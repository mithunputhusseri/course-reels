Practice · Q1–Q2

Programs, processes & memory

Q1

You run the same binary three times. How many processes? How many address spaces?

A: Three processes, each with its own address space (and PCB).

Q2

Which segment typically holds return addresses and local variables? Which grows with malloc?

A: Stack for frames/locals; heap for dynamic allocation. They grow toward each other.

Check: program ≠ process; text/data load early; heap/stack change at runtime.
