Practice · Q7–Q8

fork/exec & IPC

Q7

A shell runs ls. Which call creates the child? Which replaces the child's image with ls?

A: fork creates the child; exec loads ls into that child.

Q8

When is shared memory preferred over message passing? What's the main risk?

A: Prefer when you need high throughput / low copy cost. Risk: apps must implement correct synchronization.

Check: fork clones; exec morphs. Messages = OS-mediated; shared mem = fast but sync-heavy.
