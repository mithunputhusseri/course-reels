Transitions

What moves a process between states

  • new → ready — admitted (resources granted)
  • ready → running — scheduler dispatch
  • running → ready — interrupt / time slice expired
  • running → waiting — I/O or event wait
  • waiting → ready — I/O / event completion
  • running → terminated — exit
Exam lens: name the event, not just the arrow — e.g. "time slice expired" not only "back to ready."
