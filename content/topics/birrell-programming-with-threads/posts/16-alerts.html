Alerts: diverting control

Alerts unwind a long wait or computation (CANCEL a query; stop losing parallel search).

  • Alert(t) — set pending bit; wake if in AlertWait
  • Long waits → AlertWait; long loops → periodic TestAlert
  • SRC convention: only alert threads you forked (≈ "please terminate")
  • Prefer a boolean + Signal when you know the condition
TRY
  WHILE empty DO AlertWait(m, nonEmpty) END;
  RETURN NextChar()
EXCEPT Alerted: RETURN EndOfFile END;
Warning: alerts weaken local reasoning — use sparingly or code becomes unreadable.
