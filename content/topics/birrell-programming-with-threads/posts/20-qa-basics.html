Practice · Q1–Q2

Threads & motivation

Q1

What is shared vs private among threads in one address space?

A: Shared: off-stack / global memory. Private: each thread's call stack and locals.

Q2

Name two ways concurrency helps even without many CPUs.

A: Overlap slow-device waits; defer housekeeping to cut latency / keep UI responsive.

Check: lightweight = create/sync cheap enough for ordinary concurrency needs.
