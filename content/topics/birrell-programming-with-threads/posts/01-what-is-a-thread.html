Birrell · 1989

What is a thread?

A thread is one sequential flow of control — own PC, own stack, ordinary procedure calls.

  • Shared — globals / heap in one address space
  • Private — each thread's stack and locals
  • Lightweight — create, sync, destroy cheap enough for everyday concurrency
Birrell's term: process = one flow tied 1:1 to an address space. A thread is a flow inside a shared space.
