Pipelines with Fork

Stages connected by producer–consumer queues; each stage is a thread.

  • Balanced 3-stage pipeline → up to 3 processors
  • Helps on 1 CPU when stages wait on I/O / faults
  • Throughput limited by the slowest stage
  • Static concurrency = # of stages (awkward when CPU count changes)
Capacity: many blocked threads are cheap; too many runnable threads thrash the scheduler.
