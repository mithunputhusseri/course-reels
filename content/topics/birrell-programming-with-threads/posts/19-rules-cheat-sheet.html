Cheat sheet

Rules worth tattooing

  • Protect every shared mutable datum — one clear mutex
  • Mutex = invariant; restore before unlock / Wait
  • Acquire locks in a consistent partial order
  • Keep critical sections short; rare conflicts
  • WHILE NOT pred DO Wait — always
  • Signal if ≤1 can proceed; Broadcast if many / simpler
  • Often Signal after unlock
  • Fork for real work; bound runnable threads
  • Alert sparingly; only threads you created
Closing: concurrent programming need not be exotic — good primitives + discipline beat cleverness.
