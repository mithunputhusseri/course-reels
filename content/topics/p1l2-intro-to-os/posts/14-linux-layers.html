Linux

Layers from user to hardware

  1. Users / apps — people and programs
  2. Standard utilities — shell, editors, compilers
  3. C library — open, read, write, fork, …
  4. System-call interface — crosses into kernel mode
  5. Linux kernel — process, memory, FS, I/O, …
  6. Hardware — CPU, memory, disks, terminals
Key boundary: libc wraps syscalls; the kernel owns privileged work below that line.
