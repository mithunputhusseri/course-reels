macOS

Layers top → bottom

  • Aqua — graphical UI
  • App environments — Cocoa, QuickTime, Java, BSD userland services
  • Kernel environment — Mach (IPC, tasks/threads, address spaces) + BSD (Unix process/FS semantics)
  • Low-level I/O — I/O Kit and kernel extensions

Design mix

Microkernel influence (Mach) + monolithic/hybrid performance (BSD in kernel) + modularity (kexts / driver kits).
