Wrap-up

Remember these four lines

  1. Monolithic — speed & integration; pays in size, customization, bug blast radius
  2. Modular — plug in FS/schedulers/drivers; better footprint, some indirection
  3. Microkernel — tiny trusted base & isolation; IPC and server complexity cost
  4. In the wild — Linux ≈ modular monolithic; macOS ≈ Mach + BSD hybrid
Exam lens: ask where the service runs and how components talk (direct call vs module API vs IPC).
