Case study

Flash: event-driven + AMPED helpers

  • Event-driven web server (AMPED)
  • Asymmetric helpers for disk reads
  • Pipes between helpers and dispatcher
  • Helpers map files (mmap); dispatcher checks residency (mincore)

If pages are already in memory, handle locally — otherwise send work to a helper. That can save a lot.

Extra optimizations

Response-header cache, pathname translation cache, mapped-file cache, DMA alignment, scatter-gather, vector I/O.
