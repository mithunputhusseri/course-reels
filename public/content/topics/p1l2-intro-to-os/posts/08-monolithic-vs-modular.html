Monolithic vs modular

Monolithic

Tight coupling, all-in-one. Extending often means rebuild/patch. Larger fixed footprint. Direct function calls. Weak failure isolation.

Modular

Looser coupling via interfaces. Load/replace modules. On-demand footprint. Some indirection. Better for some faults — modules still often share kernel space.

Nuance: modular ≠ microkernel. Modules can still run inside the kernel.
