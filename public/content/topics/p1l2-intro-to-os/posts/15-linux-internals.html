Linux

Kernel internals via syscalls

  • I/O / VFS — virtual FS, sockets, block layer, network stack, drivers
  • Memory — virtual memory, paging, page cache
  • Process mgmt — signals, create/terminate, CPU scheduling
  • Interrupts + dispatcher — hardware events enter; work is routed
Practice tip: load only needed drivers as modules (make modules_install / LKMs) to shrink the running footprint — modular idea inside a monolithic kernel.
