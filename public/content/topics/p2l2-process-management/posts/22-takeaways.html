Wrap-up

Quick takeaways

  1. Process = running program + state; one binary → many processes
  2. Address space = text/data/heap/stack mapped via page tables
  3. PCB = stop/resume snapshot; heart of a context switch
  4. Lifecycle = new → ready → running, with waiting & terminate
  5. Create with fork + exec; scheduler balances \(T_p\) vs \(T_s\)
  6. IPC = messages (safer/slower) or shared memory (fast/harder)
Exam lens: ask where state lives (CPU vs PCB vs memory) and who mediates communication.
