Segments

Text, data, heap, stack

  • Text — machine instructions; loaded at start; usually R/X
  • Data — initialized globals / statics; loaded at start
  • Heap — dynamic objects (malloc); grows / shrinks at runtime
  • Stack — frames, locals, return addresses; LIFO; grows / shrinks
Exam tip: text & data are set up at load time; heap & stack change while the process runs.
