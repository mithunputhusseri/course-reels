Definition

What's inside a process?

A process is an instance of an executing program — everything needed to run it.

  • Execution state — PC, stack pointer, CPU registers
  • Memory / data — text, data, heap, stack
  • OS resources — open files, signal masks, I/O devices
task ≈ job ≈ process
Key: the process encapsulates code, working storage, and kernel-managed resources.
