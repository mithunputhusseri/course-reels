Scheduling resources

Condition variables

A monitor = data + mutex + zero or more conditions. Always pair a condition with one mutex.

  • Wait(m,c) — atomically unlock m and sleep on c
  • Signal(c) — wake ≥1 waiter (maybe more); no-op if none
  • Broadcast(c) — wake all current waiters
  • Woken thread must re-lock m before Wait returns
Atomic Wait prevents the wake-up-waiting race: a signal can't sneak in between "decide to sleep" and "actually sleep."
