Motivation

Five reasons to use concurrency

  • Multiprocessors — use cores without paying process/IPC setup cost (~≤10 CPUs in Birrell's era)
  • Slow devices — disk/net wait in one thread; others keep working
  • Humans — UI actions in parallel; don't freeze the display
  • Servers — many clients without one process per client
  • Lower latency — return the answer, rebalance the tree in a background thread
Even on 1 CPU: deferring work can improve responsiveness while total work stays the same.
