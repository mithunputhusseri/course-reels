Build order

Useful → correct → live → efficient

Useful

Assume multi-threaded callers. Re-entrant APIs. No results in shared globals. Prefer sync calls.

Correct

One mutex per datum. Predicate loops around Wait. Answers match the spec.

Live

Eventually finishes. Avoid deadlock / infinite wait. Debugger must show all stacks + lock holders.

Efficient

Measure lock conflicts & runnable-thread counts. Never trade correctness for speed.

Quote the order: easier to speed up a correct program than to un-bug an "optimized" one.
