Classic pattern

Readers / writers

AcquireExclusive: WHILE i # 0 DO Wait END; i := -1
AcquireShared:    WHILE i < 0 DO Wait END; i := i+1
ReleaseExclusive: i := 0; Broadcast   (* many readers *)
ReleaseShared:    i := i-1; IF i=0 THEN Signal END
  • Separate cR/cW cuts spurious wake-ups
  • Track writeWaiters so overlapping readers don't starve writers
Restraint: simple ~15 lines; "fair/tuned" ~30. Optimize only when load demands it.
