AMPED and AMTED helpers

Helpers are dedicated to blocking I/O. They talk to the event dispatcher over pipes/sockets so select/poll still works.

AMPED · helper processes AMTED · helper threads
  • Fixes portability limits of pure event-driven code
  • Smaller footprint than a full worker-thread pool
Still constrained by application shape and event routing on multi-CPU systems.
